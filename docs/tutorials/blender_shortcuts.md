## Custom Keybindings

Most operations are available via the **Polygons** and **Waypoints** sidebar panels (N key → panel tab).
The shortcuts below are kept for keyboard-driven export workflows only.

| Key Combination          | Action                                 |
|--------------------------|----------------------------------------|
| `Ctrl + Shift + E`       | Export selected polygon(s)             |
| `Ctrl + Alt + E`         | Export all polygons                    |
